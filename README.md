# SchemaChef
This AI-supported application transforms recipes from any language into schema.org conformant recipes in a selectable target language and saves them to XWiki, ready for scraping.

## Features
- select AI provider (Gemini, ChatGPT, Claude)
- select target language
- customize templates for ingredients and recipe instructions for improved scraping compatibility (e.g., by [KitchenOwl](https://github.com/tombursch/kitchenowl))
